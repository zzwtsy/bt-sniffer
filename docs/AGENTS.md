# 文档任务入口

先读[文档目录设计](architecture/documentation-layout.md)与[写作规则](development/documentation.md)，再核对对应源码、配置和测试。仓库级授权与交付边界由[根 AGENTS](../AGENTS.md)维护，本目录不重复定义。

业务专题以源码与验证入口开头；参数、事件字段和状态机分别在唯一专题维护。目录和导航只提供地图，变更时同步真实引用。未知历史动机不补写为事实，操作示例说明前提、副作用、成功判据和停止方式。

保留本地 plans、外部协议资料与任务范围外的运行数据。现行文档不积累实施流水账；验证证据保存在既有忽略目录。检查选择 docs，工具同步修改时加 tools；完成前人工核对读取路径及事实归属。
