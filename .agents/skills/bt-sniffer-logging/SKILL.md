# bt-sniffer 日志

## 入口与范围

Rust 主工作流仍使用 rust-readable-apps；本 skill 只补充日志专项判断。
先读取 [日志契约](../../../docs/logging.md)、[运行约束](../../../docs/rust-development.md)
和 Cargo.lock，再定位应用日志初始化、相关事件、测试及消费者。
区分只读审查、文案修正、事件调整和输出行为变更；只处理用户授权范围。
当前策略和字段以项目文档及实际代码为依据，不把某个版本的策略变成通用限制。

## 事件与统计

- 本程序可消费的事件使用稳定 event、schema_version；target 使用实际模块路径。
  中文 message 供阅读，不从错误文案或 Debug 文本推导业务分类。
- 计数、布尔和耗时保留类型，名称标明必要单位；零、缺失、溢出分别表达。
  修改字段类型、含义或输出编码时核对版本与消费者，不静默改变契约。
- 领取、执行得到内容、事务 Applied、通知取消、任务退出分别记录；日志投递不等于写入或持久化。
- 完整计数与限量样本分开。保留样本额度、截断和 suppressed 统计；过滤或丢弃时，获准样本数不是实际输出数。
- 聚合保持固定维度，不引入 hash/IP 等长期指标标签。跨区间领取和提交不直接相除；先合并桶再算分位数。
- 业务计数和状态修改不放进日志宏参数或 enabled! 条件中，避免过滤影响程序行为。

## 级别与错误边界

- INFO 记录重要生命周期、状态和聚合；DEBUG 记录具体排障上下文。
  公网 peer 常见拒绝、超时和协议失败优先进入现有分类聚合及限量样本。
- WARN 表示值得关注的异常或降级；ERROR 表示操作失败或关键能力失效。
  返回 Err 不自动等于 ERROR，可继续运行也不自动降为 WARN。
- 错误说明操作、阶段、影响及后续动作，底层原因放独立 error 字段。
  %error 只保证 Display，不保证完整 source 链。
- 明确错误详情记录边界，避免沿调用栈重复打印。即时状态通知和退出诊断可能有不同职责，
  不通过字符串全局去重改变错误次数、收尾结果或退出码。
- 外部说明按实际风险限长、转义；不输出原始 metadata、报文、凭证或整个配置对象。

## tracing 与异步

需要跨事件定位一次操作时才加 span，不给每个函数或报文都建 span。
instrument 优先 skip_all，再声明必要字段；不随意用 err/ret 输出所有错误和返回对象。
后补字段先声明 Empty。生产必需上下文不能只存在于默认被禁用的 span。

异步 future 用 instrument 关联；新任务、专用线程和通道消费端按需要显式传播上下文。
enter guard 不跨 await；span 关闭不等于成功，也不能代替业务计时或完成确认。
相关修改再读取 rust-async-patterns；示例见 [tracing 用法](references/tracing.md)。

## 输出、过滤与资源

应用入口统一初始化 subscriber，业务模块不安装全局 subscriber。
按需求选择全局或每层过滤，不自动添加配置入口、热更新或后端框架。
外部过滤输入严格校验；明确默认值、替换语义及关闭日志对诊断证据的影响。

后台 writer 仍有调用线程格式化开销。保留有界队列、单条内容限制与明确满载策略；
lossy(false) 会阻塞线程，并非异步等待。输出端健康分别观察，不把丢弃计数解释为全部 I/O 错误。
先获取诊断快照再输出，避免报告之间相互影响。guard 由入口持有至最终事件之后；
有限刷新等待、文件轮转数量和磁盘字节上限是不同保证。

## 验证与交付

- 新事件用局部 subscriber 检查字段类型和业务口径，不依赖整行文本。
- 异步测试绑定 future 的 subscriber；涉及 spawn 时核对 subscriber 与 span 两种传播。
- 初始化、环境变量、实际双端输出和退出使用隔离子进程；不修改测试进程全局环境或 subscriber。
- 输出变化覆盖慢端、投递丢弃、初始化失败和正常关闭；不为日志测试启动公网长测。
- 文案任务只核对代码契约与链接，不改实现。代码任务按项目检查流程验证。
- 迁移同步更新消费者、说明和示例；完整坏行报告错误，未完成末行等待后续数据。
  历史报告和旧日志保留原有含义，不改写成新版本。

交付说明真实修改、实际验证和剩余边界，不把新增日志当成性能改善或持久化证明。
